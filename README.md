# Práctica 9 - Rescate Marino

El juego usa las clases e interfaces del diagrama UML y una temática marina.
Controlas a un buzo que debe recoger 3 perlas, activar 2 boyas y llegar al submarino,
ientras evita a 3 tiburones.

## Controles

- Flechas o WASD: mover
- Espacio: atacar
- F: usar botiquín
- M: movimiento aleatorio
- R: reiniciar
